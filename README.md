## About me

Software engineer from Murcia. I have been building web products and infrastructure since the mid-2000s, and I have led technology at DIGIO since **2007**.

This account is the playground: Rust and Go CLIs, MCP servers, Lua/GopherLua extensions, old PHP frameworks, Android/Titanium experiments, and whatever I am curious about next. Languages I keep coming back to: **Rust**, **Go**, **Crystal**, TypeScript, Python.

I also write notes at [sevir.org](https://www.sevir.org/).
